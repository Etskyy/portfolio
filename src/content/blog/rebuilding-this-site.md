Rebuilt loxton.dev from scratch. Wanted a portfolio that actually shows ongoing work rather
than a static list of projects that never changes, so posts here can either sit on their own
in the general feed or get tagged to a specific project and show up as an update log on that
project's page as well.

Everything is plain Markdown under the hood, so adding a new post is just a new file and a
git push, no separate CMS or database involved.
